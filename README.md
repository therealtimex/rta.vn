# rta.vn

Static HTML, CSS, JavaScript and assets for https://rta.vn.

GitHub Pages publishes the repository root from the `main` branch. Edit the files and push to `main` to publish changes. No WordPress, database, npm packages or build step is required.

`CNAME` selects the custom domain; `.nojekyll` preserves the existing static assets and directory names.

Old archive URLs use small HTML redirects. Historic image URLs recover when opened in a browser via the custom 404; old image hotlinks embedded in external sites cannot use those HTML redirects.
